MAC Products Internal Jargon Glossary
=====================================
This glossary translates internal MAC Products terminology into M2M / UniPoint
schema fields and values. ALWAYS use these mappings when a user asks about a
term listed below — do not infer the mapping from general M2M knowledge.

# Inventory & Parts (M2M)

- "raw material" / "raw materials" / "raw" → INMASTX.FPRODCL = '00'
- "finished good" / "finished goods" / "FG" → INMASTX.FPRODCL with non-raw classes (filter FPRODCL <> '00')
- "buy item" / "purchased part" → INMASTX.FCPURCHASE = 'Y' (or INMASTX.FSOURCE = 'B')
- "make item" / "made part" / "manufactured part" → INMASTX.FCPURCHASE = 'N' (or INMASTX.FSOURCE = 'M')
- "phantom" → INMASTX.FSOURCE = 'P'
- "stock item" → INMASTX.FSOURCE = 'S'
- "product class" / "PC" → INMASTX.FPRODCL
- "ABC code" / "valuation class" → INMASTX.FABCCODE ('A', 'B', or 'C')

# Inventory Locations (M2M)
# When a user mentions a location, they mean the FLOCATION field on the
# INONHD table (inventory on hand) or the LOCATION master table. The query
# should filter INONHD.FLOCATION (or JOIN to LOCATION for descriptions).
# Use RTRIM() on FLOCATION since it is a CHAR field.
#
# Active location codes and what users call them:
- "22 Penn" / "Pennsylvania" → FLOCATION = '22PENN' (22 Pennsylvania Ave Building)
- "receiving" / "incoming" → FLOCATION = 'IN' (Incoming Material Receiving)
- "non-stocked" / "NS" → FLOCATION = 'NS' (Non Stocked Item)
- "pineapple" / "PAA" → FLOCATION = 'PAA' (Pineapple Assembly Area)
- "prepack" → FLOCATION = 'PK' (Prepack Area)
- "pumping plant" / "PP" → FLOCATION = 'PP' (Pumping Plant Staging)
- "building 1" / "PPBLD1" → FLOCATION = 'PPBLD1' (Power Properties Building 1)
- "building 2" / "PPBLD2" → FLOCATION = 'PPBLD2' (Power Properties Building 2)
- "QC" / "inspection" / "quality" → FLOCATION = 'QC' (Inspection)
- "QC approved" → FLOCATION = 'QC-APPROVED'
- "QC rejected" → FLOCATION = 'QC-REJECTED'
- "return to supplier" / "RTS" → FLOCATION = 'QC-RETURNSUPPL'
- "QC rework" / "rework" → FLOCATION = 'QC-REWORK'
- "QC sample" / "sample" → FLOCATION = 'QC-SAMPLE' (QC Sample Retain Area)
- "Goodyear" / "RG" → FLOCATION = 'RG' (Goodyear)
- "safe" / "safe box" → FLOCATION = 'SAFE' (Safe Box — also SAFE2, SAFE3)
- "splice kit" / "SP" → FLOCATION = 'SP' (Splice Kit Area)
- "suite 400" / "warehouse 400" → FLOCATION = 'SUITE400' (Warehouse 400)
- "switch room" / "SW" → FLOCATION = 'SW' (Switch Room)
- "tape area" / "TA" → FLOCATION = 'TA' (Tape Area)
- "warehouse" / "WH" → FLOCATION = 'WH' (Warehouse — the main warehouse)
- "wiring room" / "WR" → FLOCATION = 'WR' (Wiring Room)
- "GE" → FLOCATION = 'GE'
#
# Obsoleted locations (still in LOCATION table but rarely queried):
#   BUYRESELL, C.TIP, CA, RC, RM, SCRAP, WA
#
# To show on-hand quantity at a location:
#   SELECT RTRIM(i.FPARTNO) AS PartNo, i.FONHAND AS OnHand, RTRIM(i.FBINNO) AS Bin
#   FROM INONHD i WHERE RTRIM(i.FLOCATION) = '<CODE>' AND i.FONHAND <> 0
#
# To list everything across all locations for a part:
#   SELECT RTRIM(i.FLOCATION) AS Location, i.FONHAND AS OnHand
#   FROM INONHD i WHERE RTRIM(i.FPARTNO) = '<PARTNO>' AND i.FONHAND <> 0

# Sales Orders (M2M)

- "open SO" / "open orders" → SOMAST where RTRIM(FSTATUS) NOT IN ('Closed', 'Cancelled')
- "closed SO" → SOMAST where RTRIM(FSTATUS) = 'Closed'
- "cancelled SO" → SOMAST where RTRIM(FSTATUS) = 'Cancelled'
- "late order" / "past due" → SOMAST where FDUEDATE < GETDATE() and FSTATUS not in ('Closed','Cancelled')
- "Wabtec orders" / "Wabtec sales orders" → SOMAST where FPRODCL = '04' (Wabtec product class — NOT customer number)

# Quality (UniPoint)

- "NCR" / "non-conformance" / "non-conformance report" → PT_NC table
- "open NCR" → PT_NC where Status NOT IN ('Closed', 'Void')
- "CPA" / "corrective action" / "corrective/preventive action" → PT_CPA table
- "inspection" → PT_Inspection table

# Date Conventions

- 1899-12-31 and 1900-01-01 are M2M sentinels meaning "not set" — filter them out when displaying dates.

# Notes

If a user uses a term that maps here, apply the mapping silently — don't ask
for confirmation. If a term is ambiguous, briefly mention which mapping you
used in the explanation.
